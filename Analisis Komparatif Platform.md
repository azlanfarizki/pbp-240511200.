## Bagian 3: Refleksi

Dari ketiga platform yang telah saya cermati, platform Web merupakan yang paling menarik untuk saya pelajari lebih dalam. Minat ini muncul karena sifat web yang lintas platform dan bisa  diakses dari berbagai perangkat, kapan saja, tanpa perlu pengguna melakukan instalasi yang membebani memori. Selain itu, pengembangan web sangat sesuai dengan minat saya dalam pengelolaan database dan otomatisasi sistem (seperti Python dan AI). Teknologi web sering kali menjadi "wajah" atau antarmuka utama yang paling ramah pengguna untuk menampilkan hasil pengolahan data atau sistem cerdas (seperti chatbot) kepada masyarakat.

Namun, saat mempersiapkan lingkungan pengembangan dasar (setup environment), saya menghadapi beberapa tantangan teknis. Tantangan terberat adalah terbiasa untuk berinteraksi dengan sistem melalui Command Line Interface (CLI) di terminal. Pemrosesan bahwa instalasi Node.js dan NPM sudah terdaftar dengan benar di Environment Variables Windows, serta memahami alur kerja Git (yang mencakup clone, commit, dan push ke GitHub) memerlukan ketelitian  ekstra, karena jika ada  kesalahan kecil pada saat menggunakan perintah terminal dapat menyebabkan error saat sinkronisasi. 

Untuk mengatasi masalah tersebut, rencana saya agar lebih sering berlatih langsung dengan terminal supaya lebih memahami dasar ekosistem. Saya akan mencatat langkah demi langkah alur kerja Git, serta Merujuk pada dokumentasi resmi dan tutorial visual jika mengalami error. Di sisi lain, saya juga berencana untuk melakukan commit secara rutin dengan pesan yang jelas agar riwayat pekerjaan saya tetap aman dan teratur.
